## search

Search for company logos and brand assets by ticker symbol or company name for use in financial applications and dashboards.

### Example Usage

<!-- UsageSnippet language="python" operationID="searchLogos" method="get" path="/v1/logos/search" -->
```python
from finance_dev import FinanceDev, models


with FinanceDev(
    security=models.Security(
        client_id="<YOUR_CLIENT_ID_HERE>",
        client_secret="<YOUR_CLIENT_SECRET_HERE>",
    ),
) as fd_client:

    res = fd_client.logos.search(search_keys="AAPL,MSFT", fields="logo_light,logo_dark,mark_light,mark_dark", search_keys_type=models.SearchLogosSearchKeysType.SYMBOL, composite_auto=False)

    assert res.logo_search_response is not None

    # Handle response
    print(res.logo_search_response)

```

## sync

Synchronize and retrieve the latest company logos ensuring brand assets are up-to-date across all platforms.

### Example Usage

<!-- UsageSnippet language="python" operationID="syncLogos" method="get" path="/v1/logos/sync" -->
```python
from finance_dev import FinanceDev, models


with FinanceDev(
    security=models.Security(
        client_id="<YOUR_CLIENT_ID_HERE>",
        client_secret="<YOUR_CLIENT_SECRET_HERE>",
    ),
) as fd_client:

    res = fd_client.logos.sync(fields="logo_light,logo_dark,mark_light,mark_dark", composite_auto=False, page=0, page_size=10)

    while res is not None:
        # Handle items

        res = res.next()

```
