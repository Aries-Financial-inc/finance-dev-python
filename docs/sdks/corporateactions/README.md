## get_dividends

Retrieve historical dividend payments including declaration dates, ex-dividend dates, payment dates, and dividend amounts per share. `ticker` accepts a single symbol only. Use `tickersAnyOf` for multiple symbols. If `ticker` contains multiple comma-separated values, the API returns 400: "Multiple tickers are not supported. Please provide a single ticker." If both `ticker` and `tickersAnyOf` are set, the API returns 400: "Cannot specify both ticker and tickersAnyOf. Use ticker for a single symbol or tickersAnyOf for multiple."

### Example Usage

<!-- UsageSnippet language="python" operationID="getDividends" method="get" path="/v1/corporate-actions/dividends" example="default" -->
```python
from datetime import date
from finance_dev import FinanceDev, models


with FinanceDev(
    security=models.Security(
        client_id="<YOUR_CLIENT_ID_HERE>",
        client_secret="<YOUR_CLIENT_SECRET_HERE>",
    ),
) as fd_client:

    res = fd_client.corporate_actions.get_dividends(ticker="AAPL", tickers_any_of="AAPL,MSFT,GOOG", ticker_from="A", ticker_after="A", ticker_to="Z", ticker_before="Z", ex_dividend_date=date.fromisoformat("2024-08-11"), ex_dividend_date_from=date.fromisoformat("2024-01-01"), ex_dividend_date_after=date.fromisoformat("2024-01-01"), ex_dividend_date_to=date.fromisoformat("2024-12-31"), ex_dividend_date_before=date.fromisoformat("2024-12-31"), frequency=4, frequency_min=1, frequency_above=0, frequency_max=12, frequency_below=13, distribution_type=models.DistributionType.RECURRING, distribution_types="recurring,special", limit=100)

    while res is not None:
        # Handle items

        res = res.next()

```

## get_stock_split

Retrieve historical stock split events including split ratios, execution dates, and pre/post-split price adjustments. `ticker` accepts a single symbol only. Use `tickersAnyOf` for multiple symbols. If `ticker` contains multiple comma-separated values, the API returns 400: "Multiple tickers are not supported. Please provide a single ticker." If both `ticker` and `tickersAnyOf` are set, the API returns 400: "Cannot specify both ticker and tickersAnyOf. Use ticker for a single symbol or tickersAnyOf for multiple."

### Example Usage

<!-- UsageSnippet language="python" operationID="getStockSplits" method="get" path="/v1/stock/split" example="default" -->
```python
from datetime import date
from finance_dev import FinanceDev, models


with FinanceDev(
    security=models.Security(
        client_id="<YOUR_CLIENT_ID_HERE>",
        client_secret="<YOUR_CLIENT_SECRET_HERE>",
    ),
) as fd_client:

    res = fd_client.corporate_actions.get_stock_split(ticker="AAPL", tickers_any_of="AAPL,TSLA,NVDA", ticker_from="A", ticker_after="A", ticker_to="Z", ticker_before="Z", execution_date=date.fromisoformat("2020-08-31"), execution_date_from=date.fromisoformat("2020-01-01"), execution_date_after=date.fromisoformat("2020-01-01"), execution_date_to=date.fromisoformat("2024-12-31"), execution_date_before=date.fromisoformat("2024-12-31"), adjustment_type=models.GetStockSplitsAdjustmentType.FORWARD_SPLIT, adjustment_types="forward_split,reverse_split", limit=100)

    while res is not None:
        # Handle items

        res = res.next()

```
