# NetInflow

Net market inflow snapshot for Nasdaq and NYSE. Use it to show whether reported flow is net buying or net selling.


## Fields

| Field                                                                                                                      | Type                                                                                                                       | Required                                                                                                                   | Description                                                                                                                |
| -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `nasdaq_net_inflow`                                                                                                        | *Optional[float]*                                                                                                          | :heavy_minus_sign:                                                                                                         | Net inflow value for Nasdaq activity. Positive values indicate net buying flow; negative values indicate net selling flow. |
| `nasdaq_trade_count`                                                                                                       | *Optional[int]*                                                                                                            | :heavy_minus_sign:                                                                                                         | Number of Nasdaq trades included in the inflow calculation.                                                                |
| `nyse_net_inflow`                                                                                                          | *Optional[float]*                                                                                                          | :heavy_minus_sign:                                                                                                         | Net inflow value for NYSE activity. Positive values indicate net buying flow; negative values indicate net selling flow.   |
| `nyse_trade_count`                                                                                                         | *Optional[int]*                                                                                                            | :heavy_minus_sign:                                                                                                         | Number of NYSE trades included in the inflow calculation.                                                                  |
| `timestamp`                                                                                                                | *Optional[str]*                                                                                                            | :heavy_minus_sign:                                                                                                         | Data timestamp in ISO 8601 format; fractional seconds may be present (for example microseconds).                           |
