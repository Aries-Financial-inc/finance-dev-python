# StockOhlcBar

OHLCV bar for stock price history. Use values at each bar to render candles or historical price charts.


## Fields

| Field                                                                                 | Type                                                                                  | Required                                                                              | Description                                                                           |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `ticker_symbol`                                                                       | *Optional[str]*                                                                       | :heavy_minus_sign:                                                                    | Ticker symbol (optional, e.g. for grouped/prev)                                       |
| `c`                                                                                   | *Optional[float]*                                                                     | :heavy_minus_sign:                                                                    | Close price for the bar interval. Use it as the final price in a candle.              |
| `h`                                                                                   | *Optional[float]*                                                                     | :heavy_minus_sign:                                                                    | Highest traded price during the bar interval. Use it for the candle's upper wick.     |
| `l`                                                                                   | *Optional[float]*                                                                     | :heavy_minus_sign:                                                                    | Lowest traded price during the bar interval. Use it for the candle's lower wick.      |
| `n`                                                                                   | *Optional[int]*                                                                       | :heavy_minus_sign:                                                                    | Number of trades included in the bar. Use it as an activity indicator when available. |
| `o`                                                                                   | *Optional[float]*                                                                     | :heavy_minus_sign:                                                                    | Opening price for the bar interval. Use it as the first price in a candle.            |
| `t`                                                                                   | *Optional[int]*                                                                       | :heavy_minus_sign:                                                                    | Bar timestamp in Unix milliseconds. Use it as the x-axis time value.                  |
| `v`                                                                                   | *Optional[float]*                                                                     | :heavy_minus_sign:                                                                    | Shares or contracts traded during the bar interval. Use it for volume charts.         |
| `vw`                                                                                  | *Optional[float]*                                                                     | :heavy_minus_sign:                                                                    | Volume weighted average price                                                         |
