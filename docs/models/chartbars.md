# ChartBars

Historical chart data returned as parallel arrays. Values at the same index belong to the same bar, so `t[0]`, `o[0]`, `h[0]`, `l[0]`, `c[0]`, and `v[0]` describe one candle.

| --------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |

Use the value at the same index as `t` for chart candles and performance calculations.                        |
| `errmsg`                                                                                                                                | *Optional[str]*                                                                                                                         | :heavy_minus_sign:                                                                                                                      | Human-readable error message. Use it for candle wicks and intraperiod range.                                           |
