# QuoteValues

Market quote values for a symbol. Use bid/ask for trading decisions and last price for display context.


## Fields

| Field                                                                                                                                      | Type                                                                                                                                       | Required                                                                                                                                   | Description                                                                                                                                |
| ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `ask`                                                                                                                                      | *Optional[float]*                                                                                                                          | :heavy_minus_sign:                                                                                                                         | Lowest price sellers are currently willing to accept. Buyers usually compare their limit price to the ask.                                 |
| `bid`                                                                                                                                      | *Optional[float]*                                                                                                                          | :heavy_minus_sign:                                                                                                                         | Highest price buyers are currently offering. Sellers usually compare their limit price to the bid.                                         |
| `ch`                                                                                                                                       | *Optional[float]*                                                                                                                          | :heavy_minus_sign:                                                                                                                         | Dollar price change from the previous close. Use this for quote tiles and daily move displays.                                             |
| `chp`                                                                                                                                      | *Optional[float]*                                                                                                                          | :heavy_minus_sign:                                                                                                                         | Percent change from the previous close. Use this to show the daily move as a percentage.                                                   |
| `description`                                                                                                                              | *Optional[str]*                                                                                                                            | :heavy_minus_sign:                                                                                                                         | Full company or instrument description. Show it when users need to confirm the symbol they are viewing.                                    |
| `exchange`                                                                                                                                 | *Optional[str]*                                                                                                                            | :heavy_minus_sign:                                                                                                                         | Exchange code where the data originates. Format depends on the upstream data source and may use MIC, ISO 10383, or a vendor-specific code. |
| `high_price`                                                                                                                               | *Optional[float]*                                                                                                                          | :heavy_minus_sign:                                                                                                                         | Highest price for the day                                                                                                                  |
| `low_price`                                                                                                                                | *Optional[float]*                                                                                                                          | :heavy_minus_sign:                                                                                                                         | Lowest traded price during the current session. Use it for daily range displays.                                                           |
| `lp`                                                                                                                                       | *Optional[float]*                                                                                                                          | :heavy_minus_sign:                                                                                                                         | Last traded price. Use this as the current reference price, but use bid and ask when estimating immediate buy or sell cost.                |
| `open_price`                                                                                                                               | *Optional[float]*                                                                                                                          | :heavy_minus_sign:                                                                                                                         | Opening price for the day                                                                                                                  |
| `prev_close_price`                                                                                                                         | *Optional[float]*                                                                                                                          | :heavy_minus_sign:                                                                                                                         | Previous day's closing price                                                                                                               |
| `short_name`                                                                                                                               | *Optional[str]*                                                                                                                            | :heavy_minus_sign:                                                                                                                         | Short name of the company                                                                                                                  |
| `volume`                                                                                                                                   | *Optional[float]*                                                                                                                          | :heavy_minus_sign:                                                                                                                         | Number of shares or contracts traded during the current session, when available.                                                           |
