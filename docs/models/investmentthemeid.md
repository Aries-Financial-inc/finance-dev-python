# InvestmentThemeID

Investment theme identifier. Pick a theme to filter or look up stocks tied to that thesis (e.g. AI, fintech, clean energy).

## Example Usage

```python
from finance_dev.models import InvestmentThemeID

value = InvestmentThemeID.FINANCIAL_EXCHANGES_DATA

# Open enum: unrecognized values are captured as UnrecognizedStr
```
