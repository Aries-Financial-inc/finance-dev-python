# SectorAvgChange

Average percentage move by sector. Use it to compare which sectors are leading or lagging the market.


## Fields

| Field                                                                                           | Type                                                                                            | Required                                                                                        | Description                                                                                     |
| ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `avg_change`                                                                                    | *Optional[float]*                                                                               | :heavy_minus_sign:                                                                              | Average percentage change for the sector                                                        |
| `sector`                                                                                        | *Optional[str]*                                                                                 | :heavy_minus_sign:                                                                              | Sector name, such as Technology or Financials. Use it as the label in sector performance views. |
