# EquityDetailsDTO

One equity detail object from GET /v1/marketdata/equities/details. Populated from the market-data cache with an automatic fallback. Fields are pointers in the service and omitted from JSON when unset; `hasOptions` and `isETF` are always serialized as booleans. JSON names match the Go tags (e.g. `nyseNetInflow`, `EPSDiluted`, `ytdHighDate`).
